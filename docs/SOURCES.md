## Known gaps

- Legacy binary `.xls` and PDF-only lists are not parsed (UAE UAEIEC `.xls`, Bahrain gazette PDF, Oman PDFs, India NSE `.xls`); the OpenSanctions mirrors cover the UAE and others.
- Several publishers block non-browser User-Agents; those sources set an explicit `headers` override (see each source's `headers`).
- Some publishers rotate hashed file names per update (Turkey MASAK, Tunisia, Kenya, Indonesia, Malaysia, Azerbaijan); the `notes` explain how to rediscover the current URL.
- Wanted-person, ICIJ and several registry parsers were written from format notes and synthetic fixtures without a verified full parse of the real file.
- Country-risk data (FATF, Basel, CPI) is not yet ingested.
